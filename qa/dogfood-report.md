### DOG-001：异步生成完成后当前写作页不刷新结果

- **严重级别：** Medium
- **影响范围：** 小说分析与剧本页；用户会看到任务已经完成，但编辑器仍显示 `{}`，容易误以为生成失败。
- **复现步骤：**
  1. 新建项目并进入“小说分析与剧本”。
  2. 点击“开始生成”。
  3. 等待任务中心的进行中数量从 1 变为 0。
  4. 留在当前页面观察小说分析编辑器。
- **预期：** 任务完成后编辑器自动展示最新分析结果。
- **实际：** 编辑器继续显示 `{}`；离开页面再返回后才出现结果。
- **证据：** `qa/screenshots/writing-analysis-desktop-1440x900.png`、`qa/screenshots/issue-writing-stale-job-complete.png`、`qa/screenshots/writing-analysis-after-revisit.png`
- **状态：** 已修复；新增首个终态任务查询失效单测，并由 Playwright 验证结果无需跳页即可出现。

### DOG-002：页面缺少站点图标

- **严重级别：** Low
- **影响范围：** 所有页面的浏览器标签与网络日志。
- **复现步骤：**

  2. 查看浏览器网络请求。

- **实际：** 浏览器请求 `/favicon.ico` 并收到 404。
- **证据：** 浏览器网络记录 `[GET /favicon.ico] 404`。
- **状态：** 已修复；新增品牌 `favicon.svg`，生产服务返回 200 `image/svg+xml`。

### DOG-003：生产单进程模式无法打开素材页

- **严重级别：** High
- **影响范围：** `build.ps1` + `start.ps1` 的生产单端口运行方式。
- **复现步骤：**
  1. 运行 `build.ps1`。
  2. 运行 `start.ps1`。
  3. 直接访问 `http://127.0.0.1:8000/assets`。
- **预期：** 返回 React 应用入口并展示“素材与提示词”页。
- **实际：** 返回 404 JSON；`/assets` 被误判为 Vite 静态资源目录。
- **证据：** 单进程端点矩阵中 `/assets` 为 404，其余八个页面深链均为 200。
- **状态：** 已修复；精确 `/assets` 与 `/assets/` 返回 SPA，`/assets/<静态文件>` 仍按静态资源处理，服务端回归、单进程端点矩阵及生产截图均通过。

### DOG-004：开发模式停止脚本可能残留热重载子进程

- **严重级别：** Medium
- **影响范围：** Windows 开发模式启停；残留进程会继续占用 3000 或 8000 端口。
- **复现步骤：**
  1. 以 `--reload` 启动后端，并通过 `npm.cmd` 启动 Vite。
  2. 记录启动脚本返回的包装进程 PID。
  3. 运行旧版 `stop.ps1`，再检查实际监听端口的子进程。
- **预期：** 停止脚本同时结束包装进程和全部子进程，并删除 PID 文件。
- **实际：** 包装进程 PID 与端口监听 PID 不同，旧脚本只停止包装进程。
- **证据：** 回归前后端包装 PID 分别为 33904、45368，实际监听 PID 分别为 29676、37740。
- **状态：** 已修复；停止脚本按子进程树由内向外递归结束，实测 3000/8000 端口、四个相关 PID 与两个 PID 文件均全部释放。
