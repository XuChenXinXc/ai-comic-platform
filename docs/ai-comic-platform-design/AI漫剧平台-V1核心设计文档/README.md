# AI 漫剧本地平台 V1 — 核心设计文档

这是一个仅供本地个人使用的 AI 漫剧制作平台。

核心目标不是制作大型 SaaS，而是用浏览器完成：

```text
小说
→ 文字模型分析与生成剧本
→ 提取角色、场景、物品
→ 生成素材提示词并调用图片模型生图
→ 从小说或剧本提取分镜
→ 生成分镜图像提示词和视频提示词
→ 调用图片模型生成关键帧
→ 调用视频模型生成分镜视频
```

## 文档

| 文件 | 内容 |

| `01-产品方案.md` | 核心范围、七步流程、页面功能、用户操作和验收标准 |

两份文档已经统一：

- 产品方案定义“做什么”。
- 技术设计定义“怎么做”。
- 技术设计不得改变产品范围。
- Provider 特有限制放在 Adapter 中，不写死在通用数据库字段中。

## V1 保留的能力

- 文字模型 API
- 图片模型 API
- 视频模型 API
- 小说分析
- 剧本生成
- 小说素材提取
- 角色提示词
- 场景提示词
- 物品提示词
- 小说或剧本分镜提取
- 分镜图像提示词
- 分镜视频提示词
- 素材图片生成
- 分镜关键帧生成
- 分镜视频生成
- 单项和批量生成

- 任务失败重试
- 视频异步任务恢复

## V1 不做

- 配音
- 字幕
- 口型同步
- BGM
- 最终视频合成
- 多用户
- 云端 SaaS
- Redis/Celery
- 在线发布

## Provider 原则

文字、图片和视频接口通过 Adapter 接入。

每个模型的特殊限制，例如：

- 时长范围
- 是否必须是整数秒
- 最大参考图数量
- 图片传入方式
- 支持的尺寸
- 是否异步任务

全部由对应 Adapter 校验，不能写死到 `shot` 或其他通用表中。

## 推荐开工顺序

1. 先打通真实图片接口和视频接口的最小纵向链路。
2. 实现项目、小说分析和剧本生成。
3. 实现素材提取、素材提示词和素材图片。
4. 实现小说/剧本分镜、图像提示词和视频提示词。
5. 实现关键帧和视频批量生成。
6. 最后补任务恢复、失效提示、文件清理和端到端测试。

## 开工前检查

- `.env` 中已经配置三类 API Key。
- 至少有一个可用文字 Provider。
- 至少有一个可用图片 Provider。
- 至少有一个可用视频 Provider。
- 已确认视频 Provider 如何接收本地关键帧：文件上传、Base64、file_id 或临时 URL。
- 已安装 SQLite 和前后端运行环境。
- 使用真实 API 前先用 MOCK Provider 跑通主链路。
