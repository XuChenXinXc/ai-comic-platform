# AI 漫剧本地平台 V1 — 核心产品方案

## 一、产品定位

开发一个仅供本地个人使用的 AI 漫剧制作网页平台。

平台运行在本机，用户通过浏览器访问，例如：

```text
http://127.0.0.1:3000
```

平台不做在线 SaaS，不做多人协作，不做账号、权限、付费、审核和云端项目管理。

V1 只解决一条核心生产链路：

```text
小说正文
→ 文字模型分析小说并生成剧本
→ 从小说提取角色、场景、物品
→ 文字模型生成角色/场景/物品提示词
→ 图片模型生成素材参考图
→ 从小说或剧本提取分镜
→ 文字模型生成分镜图像提示词和视频提示词
→ 图片模型生成分镜关键帧
→ 视频模型生成分镜视频
```

## 二、V1 必须具备的核心能力

### 1. 文字模型能力

平台通过可配置的文字模型 API 完成：

- 小说分析
- 小说转剧本
- 从小说提取角色
- 从小说提取场景
- 从小说提取重要物品
- 为角色生成图片提示词
- 为场景生成图片提示词
- 为物品生成图片提示词
- 从小说提取分镜
- 从剧本提取分镜
- 为分镜生成关键帧提示词
- 为分镜生成视频提示词
- 为全部提示词生成负向提示词
- 单项重写、扩写、缩写和重新生成

### 2. 图片模型能力

平台通过可配置的图片模型 API 完成：

- 角色参考图生成
- 场景参考图生成
- 物品参考图生成
- 分镜关键帧生成
- 使用角色、场景、物品参考图进行图生图或多参考图生成
- 单项生成和批量生成
- 多版本保留和当前版本选择
- 上传本地图片替换生成结果

### 3. 视频模型能力

平台通过可配置的视频模型 API 完成：

- 以分镜关键帧作为首帧生成视频
- 使用分镜视频提示词、动作描述、运镜描述和时长参数
- 支持视频模型的异步任务提交和轮询
- 下载视频结果到本地
- 单个分镜重新生成
- 当前场次或全部分镜批量生成
- 多版本保留和当前版本选择
- 上传本地视频替换生成结果

## 三、V1 明确不做的功能

以下功能不属于核心生产链路，V1 不实现：

- 配音和声音克隆
- 字幕生成
- 口型同步
- 背景音乐生成
- 最终视频拼接与 FFmpeg 合成
- 片头、片尾和转场渲染
- 在线发布和抖音自动上传
- 多用户、角色权限和登录系统
- 云端项目同步
- 团队协作和评论
- 复杂审批流
- Redis、Celery、消息队列和分布式任务
- 插件市场
- 计费系统

平台只需要生成并管理每个分镜的视频片段。最终成片可在后续版本增加，或先使用剪映等工具完成。

## 四、核心使用原则

- 每一步由用户主动点击执行，不自动串联下一步。
- 文字模型生成的所有内容都必须可编辑。
- 每个角色、场景、物品和分镜都可以单独重新生成。
- 批量任务中单项失败不影响其他成功项。
- 图片和视频生成结果保留多个版本，不覆盖旧文件。
- 用户可以指定某个版本作为当前使用版本。
- 修改上游内容后，下游结果标记为“可能已过期”，但不自动删除。
- 接口失败只重试当前任务，不重跑整条流程。
- 所有远程生成结果必须下载到本地，不能只保存临时 URL。

## 五、核心数据对象

平台只围绕以下对象工作：

| 对象 | 说明 |
|---|---|
| 项目 | 一篇小说及其统一画风、比例、模型配置 |
| 小说分析 | 文字模型对小说的结构化分析结果 |
| 剧本 | 从小说改编出的场次化漫剧剧本 |
| 角色 | 从小说提取的主要和必要次要角色 |
| 场景 | 从小说提取的实际出现场景及必要变体 |
| 物品 | 对剧情或画面一致性有作用的重要物品 |
| 素材图片 | 角色、场景和物品参考图的多个版本 |
| 分镜 | 从小说或剧本提取的逐镜结构化数据 |
| 关键帧 | 每个分镜用于视频生成的起始画面 |
| 分镜视频 | 视频模型生成的单镜视频片段 |
| 任务 | 文字、图片和视频接口调用任务 |

## 六、核心制作流程

V1 采用七个步骤。

### 第一步：创建项目

用户创建项目并录入小说正文。

#### 输入内容

- 项目名称
- 小说正文
- 统一画面风格
- 画面比例
- 图片输出尺寸
- 视频输出尺寸
- 默认分镜时长
- 默认文字模型
- 默认图片模型
- 默认视频模型

#### 小说输入方式

V1 支持：

- 直接粘贴文本
- 上传 TXT
- 上传 Markdown

DOCX 上传不是核心需求，暂不实现；后续需要时再增加。

#### 默认配置

| 配置 | 默认值 |
|---|---|
| 画面比例 | 16:9 |
| 图片尺寸 | 1920×1080 |
| 视频尺寸 | 16:9 |
| 默认分镜时长 | 6 秒 |
| 主要语言 | 中文 |
| 项目类型 | 单个完整故事 |

#### 用户操作

- 保存小说
- 修改小说
- 配置统一画风
- 选择默认模型
- 测试接口连接

修改小说正文后，已经生成的小说分析、剧本、素材和分镜标记为“来源已变化”。旧结果继续保留供查看。

---

### 第二步：小说分析与剧本生成

该页面包含两个页签：

```text
小说分析 | 剧本生成
```

两项都以当前小说正文为输入，调用文字模型 API。

#### 2.1 小说分析

文字模型输出结构化分析：

- 故事概述
- 题材类型
- 故事时代和地点
- 世界观
- 主要人物
- 人物关系
- 核心冲突
- 剧情时间线
- 开端、发展、升级、高潮、反转、结局
- 情绪变化
- 重要伏笔
- 适合画面化的内容
- 不容易画面化的内容
- 可能影响分镜生成的风险

#### 2.2 剧本生成

文字模型将小说改编成适合 AI 漫剧的剧本。

剧本结构：

```text
剧本
└── 场次
    ├── 场次编号
    ├── 场景名称
    ├── 时间与天气
    ├── 出场人物
    ├── 剧情目标
    ├── 人物动作
    ├── 对白
    ├── 旁白
    ├── 情绪
    └── 与下一场的衔接
```

#### 用户操作

- 生成小说分析
- 重新生成小说分析
- 编辑分析结果
- 生成完整剧本
- 重新生成完整剧本
- 重新生成单个场次
- 增加、删除和调整场次顺序
- 修改动作、对白和旁白
- 保存当前内容
- 确认当前内容

小说分析和剧本可以分别生成，互不强制依赖。剧本生成可以参考小说分析，但小说分析不是硬性门禁。

---

### 第三步：素材提取与素材提示词

素材固定从当前小说正文提取，符合用户的核心使用方式。

页面分为三个页签：

```text
角色 | 场景 | 物品
```

#### 3.1 角色提取

只提取实际影响剧情或多次出场的角色。

每个角色包含：

- 名称
- 别名
- 性别
- 年龄范围
- 身份
- 性格
- 外貌
- 发型和发色
- 身材
- 默认服装
- 服装变体
- 标志性特征
- 常见表情和动作
- 与其他角色的关系
- 出现位置
- 重要程度

#### 3.2 场景提取

只提取故事实际需要反复使用或影响构图的场景。

每个场景包含：

- 名称
- 室内或室外
- 时间
- 天气
- 建筑和环境风格
- 空间布局
- 光线
- 色彩氛围
- 主要陈设
- 出现位置
- 重要程度

同一地点在明显不同状态下可以作为不同变体，例如：

```text
办公室｜白天
办公室｜雨夜
办公室｜停电
```

#### 3.3 物品提取

只提取有实际作用的物品，例如：

- 剧情线索
- 武器
- 信件
- 手机
- 车辆
- 戒指
- 标志性饰品
- 角色长期携带的物品

普通桌椅、杯子等不单独提取，除非它们承担剧情功能。

#### 3.4 素材提示词生成

文字模型根据素材描述和项目统一画风生成：

- 主提示词
- 负向提示词
- 一致性关键词
- 图片构图建议
- 推荐图片尺寸

角色提示词重点包含：

- 身份和年龄
- 稳定五官
- 发型发色
- 身材
- 固定服装
- 标志性特征
- 标准站姿和构图
- 项目统一画风

场景提示词重点包含：

- 空间布局
- 镜头视角
- 时间天气
- 建筑风格
- 光线
- 色彩氛围
- 主要陈设
- 项目统一画风

物品提示词重点包含：

- 材质
- 形状
- 颜色
- 结构细节
- 磨损状态
- 标志性特征
- 干净背景或使用环境

#### 用户操作

- 一键提取全部素材
- 分别提取角色、场景或物品
- 新增、编辑、删除、合并素材
- 标记核心素材
- 单独生成某个素材的提示词
- 批量生成缺失提示词
- 手动修改提示词
- 保存和确认

---

### 第四步：素材图片生成

该步骤调用图片模型 API，为角色、场景和物品生成参考图。

#### 默认生成策略

为了控制成本，V1 默认每个素材只生成一张主参考图：

| 素材类型 | 默认图片 |
|---|---|
| 角色 | 半身或全身标准定妆图 |
| 场景 | 标准全景图 |
| 物品 | 标准外观图 |

用户需要时再生成侧面、其他视角、服装变体或状态变体。

#### 图片生成输入

```text
项目统一画风
+ 素材主提示词
+ 素材负向提示词
+ 模型参数
+ 可选参考图
```

#### 用户操作

- 单个素材生成图片
- 批量生成全部未生成素材
- 按角色、场景、物品批量生成
- 修改提示词后重新生成
- 上传本地图片
- 查看多个版本
- 选择当前版本
- 删除不需要的非当前版本
- 确认当前素材图片

核心角色、核心场景如果没有当前参考图，生成分镜关键帧时显示警告，但不强制阻断，用户可以选择只用文字提示词继续。

---

### 第五步：分镜提取与分镜提示词

用户可以选择分镜来源：

```text
从小说提取 | 从当前剧本提取
```

#### 5.1 分镜提取

文字模型按照所选来源拆分分镜。

每个分镜包含：

- 分镜编号
- 所属场次
- 来源文本位置
- 场景
- 出场角色
- 使用物品
- 角色左右关系
- 起始状态
- 人物动作
- 人物表情
- 对白或旁白
- 景别
- 镜头角度
- 运镜
- 预计时长
- 结束状态
- 下一镜衔接
- 画面描述

#### 分镜拆分原则

- 一个分镜只承载一个主要剧情动作或一个明确结果。
- 避免在一个分镜中连续塞入多个复杂动作。
- 明确人物数量、站位、视线和动作方向。
- 与上一镜保持角色、服装、场景、物品和动作连续性。
- 不出现当前分镜未列出的角色。
- 分镜时长由用户配置，模型限制由具体视频适配器校验，不写死在平台数据模型中。

#### 5.2 分镜图像提示词

文字模型根据分镜和已确认素材生成关键帧图片提示词：

```text
项目统一画风
+ 场景描述
+ 角色身份和服装
+ 人物左右关系
+ 人物动作和表情
+ 物品外观与位置
+ 景别、角度和构图
+ 光线和色彩
+ 一致性关键词
```

同时生成图像负向提示词。

#### 5.3 分镜视频提示词

文字模型根据分镜生成视频执行提示词，至少包含：

- 分镜持续时间
- 开场状态
- 按时间段描述动作
- 当前说话人和嘴部动作要求
- 非说话角色反应
- 物品运动
- 摄像机运动
- 环境动态
- 结束状态
- 下一镜连续性钩子
- 禁止事项

建议结构：

```text
【参考】
项目画风、角色参考、场景参考、物品参考、关键帧职责。

【执行】
0-2秒：……
2-4秒：……
4-6秒：……

【镜头】
景别、角度、运镜、焦点变化。

【禁止】
禁止角色漂移、人数错误、服装变化、物品消失、动作顺序错误。
```

#### 用户操作

- 选择小说或剧本作为来源
- 生成全部分镜
- 重新生成某个场次的分镜
- 新增、删除、拆分、合并分镜
- 拖动调整顺序
- 单独生成某个分镜的图片提示词
- 单独生成某个分镜的视频提示词
- 批量生成缺失提示词
- 手动编辑全部字段和提示词
- 保存和确认

---

### 第六步：分镜关键帧生成

该步骤调用图片模型 API，生成每个分镜的视频首帧或关键画面。

#### 关键帧输入

```text
分镜图像提示词
+ 图像负向提示词
+ 当前场景参考图
+ 当前角色参考图
+ 当前物品参考图
+ 可选上一镜关键帧
+ 图片模型参数
```

#### 参考图选择

平台自动推荐参考图，但用户可以调整：

- 场景参考图
- 角色参考图
- 物品参考图
- 上一镜关键帧

平台不按名字临时匹配，分镜中保存明确的素材 ID 和图片版本 ID。

#### 用户操作

- 单个分镜生成关键帧
- 当前场次批量生成
- 全部分镜批量生成
- 修改提示词后重新生成
- 调整参考图
- 上传本地关键帧
- 查看多个版本
- 选择当前版本
- 确认关键帧

---

### 第七步：分镜视频生成

该步骤调用视频模型 API，根据当前关键帧和视频提示词生成单镜视频。

#### 视频生成输入

```text
当前关键帧
+ 分镜视频提示词
+ 分镜时长
+ 画面比例
+ 视频模型参数
```

视频模型可能接收：

- 本地文件上传
- Base64
- 服务商文件 ID
- 公网图片 URL

这些差异由具体视频 Provider 适配器处理，不要求用户手动转换。

#### 视频任务流程

```text
提交任务
→ 保存服务商任务 ID
→ 轮询状态
→ 获取结果 URL
→ 立即下载到本地
→ 校验文件可播放
→ 展示待确认版本
```

#### 用户操作

- 单个分镜生成视频
- 当前场次批量生成
- 全部分镜批量生成
- 修改视频提示词后重新生成
- 修改时长和模型参数
- 上传本地视频替换
- 查看多个版本
- 选择当前版本
- 下载单个视频
- 批量导出当前版本视频

某个分镜失败时，只显示该分镜失败，不影响其他分镜成功结果。

## 七、页面导航

左侧导航固定为：

1. 项目小说
2. 小说分析与剧本
3. 素材与提示词
4. 素材图片
5. 分镜与提示词
6. 分镜关键帧
7. 分镜视频
8. 接口配置
9. 任务中心

接口配置和任务中心是通用页面，不属于生产步骤。

## 八、通用功能

### 1. 保存与确认

文字内容提供：

- 保存：保存当前编辑内容。
- 确认：表示当前内容可以作为后续生成依据。

确认后仍可修改。修改时，相关下游内容标记为“来源已变化”。

### 2. 版本管理

V1 只对高成本媒体产物保留多版本：

- 素材图片
- 分镜关键帧
- 分镜视频

小说分析、剧本、素材描述和分镜文本只保留当前内容及修订号，不建立复杂文本版本库。

### 3. 失效提示

平台使用输入签名判断媒体是否可能过期：

- 素材描述或提示词变化，旧素材图片显示“来源已变化”。
- 分镜内容、提示词或参考图变化，旧关键帧显示“来源已变化”。
- 关键帧、视频提示词或时长变化，旧视频显示“来源已变化”。

旧产物不删除，用户仍可继续使用或重新生成。

### 4. 批量任务

批量任务内部逐项执行：

- 单项成功立即保存。
- 单项失败记录错误后继续下一项。
- 批量结束后显示成功数和失败数。
- 支持仅重试失败项。

### 5. 任务中心

任务中心显示：

- 任务类型
- 所属项目
- 目标素材或分镜
- 使用的服务商和模型
- 状态
- 进度
- 提交时间
- 错误信息
- 重试按钮
- 取消按钮（仅尚未提交到服务商时）

### 6. 接口配置

V1 配置三类 Provider：

- 文字模型 Provider
- 图片模型 Provider
- 视频模型 Provider

每个 Provider 支持：

- 名称
- 适配器类型
- Base URL
- API Key 对应的环境变量名
- 模型名称
- 默认请求参数
- 超时时间
- 最大重试次数
- 是否启用
- 是否为默认 Provider
- 测试连接

API Key 不直接写入 SQLite，实际密钥保存在本机 `.env` 文件中。

## 九、最小可用验收标准

V1 完成必须满足：

1. 可以创建项目并保存小说正文。
2. 可以调用文字模型生成小说分析。
3. 可以调用文字模型生成可编辑剧本。
4. 可以从小说提取角色、场景和重要物品。
5. 可以为每个素材生成图片提示词和负向提示词。
6. 可以调用图片模型生成素材参考图并下载到本地。
7. 可以从小说或剧本提取分镜。
8. 每个分镜可以生成图像提示词、视频提示词和负向提示词。
9. 可以调用图片模型生成分镜关键帧。
10. 可以调用视频模型生成分镜视频并下载到本地。
11. 素材图、关键帧和视频支持多版本和当前版本选择。
12. 批量生成时单项失败不影响其他成功项。
13. 程序重启后，已经提交且有任务 ID 的视频任务可以继续查询。
14. 所有文字结果和提示词都可以人工修改。
