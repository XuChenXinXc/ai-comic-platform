# 苹果官网风格 · AI 漫剧工作台页面设计提示词

> 用途：让 AI 从零生成一个苹果官网风格的 AI 漫剧工作台前端页面（demo/视觉稿）。
> 若要把生成结果改造成本项目真实前端，请使用 `docs/apple-style-migration-prompt.md`。

```markdown
# Role（角色）
你是一位资深产品设计师与前端工程师，精通 Apple 官网（apple.com）的视觉语言：
超大字号排版、大量留白、毛玻璃、柔和渐变、克制的动效，以及"少即是多"的信息层级。
你的任务是设计一个本地 AI 漫剧生产工作台的前端页面（单页 HTML/React 均可，
优先 Tailwind CSS）。

# Skills（能力）
- Apple 视觉体系：SF Pro 风格字体栈、紧凑字距、深/浅色双主题、backdrop-blur 毛玻璃
- 信息架构：把 8 步生产流程组织成一眼可懂的工作台，而不是功能堆砌
- 交互细节：悬停微缩放、平滑过渡、骨架屏与加载态、任务实时进度反馈
- 响应式设计：桌面端为主，窄屏优雅降级为抽屉导航

# 页面结构（从上到下，逐板块实现）
1. 顶部导航栏（sticky，毛玻璃半透明）：
   - 左侧 Logo「漫制局」+ 小字副标"Local production desk"
   - 中间主导航：项目小说 / 剧本生成 / 素材库 / 分镜视频 / 配音工作台 / 视频合成 / 自由制作 / 动态漫工作区（选中态用白色文字 + 底部高亮条）
   - 右侧：「任务中心」按钮（有进行中任务时显示红色数字角标）、浅色/深色模式切换开关、「接口配置」「平台设置」图标按钮
2. Hero 欢迎区（大留白居中）：
   - 超大标题（如"把一部小说，变成一部漫剧。"），其中关键词用蓝紫渐变文字
   - 灰色次级文案一行：说明当前项目与进度
   - 两个胶囊形 CTA：「继续创作」（黑底白字）和「新建项目」（描边按钮）
3. 生产流水线步骤条（横向 8 步）：
   小说分析 → 剧本生成 → 素材库 → 分镜关键帧 → 分镜视频 → 配音字幕 → 视频合成 → 导出成片
   - 每步是圆角卡片：图标 + 名称 + 状态（完成√ / 进行中转圈 / 待开始灰点）
   - 已完成步骤可点击返回查看，下一步骤按钮高亮提示"下一步：生成分镜"
4. 项目卡片网格（3 列）：
   - 项目封面缩略图、名称、一句话梗概、进度条（百分比）、上次编辑时间
   - 卡片悬停浮起并显示操作按钮：「打开」「重命名」「删除」
   - 第一个卡片位为「+ 新建项目」虚线卡片
5. 最近任务面板：
   - 列表项：任务名、类型标签（剧本/素材/视频）、实时进度条、状态（排队中/生成中/完成/失败）
   - 行内操作：「重试」（失败时）、「取消」（生成中时）、「查看结果」
6. 底部极简页脚：版本号 V1、存储目录提示、快捷键说明

# 关键按钮清单（必须全部出现）
- 「新建项目」    - 「继续创作」    - 「AI 分析小说」  - 「生成剧本」
- 「AI 提取素材」  - 「手工新增」    - 「生成关键帧」   - 「生成分镜视频」
- 「开始配音」     - 「生成字幕」    - 「添加 BGM」    - 「开始合成」
- 「导出成片」     - 「重试」        - 「取消任务」     - 「查看结果」
- 「接口配置」     - 「平台设置」    - 「切换项目」下拉框

# 交互规则
- 当任务生成中时，对应按钮显示加载态（转圈 + 文案变为"生成中…"）且禁止重复提交
- 当存在进行中任务时，任务中心角标实时显示数量，完成一条动画递减
- 点击"新建项目"弹出居中模态框：项目名输入、一句话简介、封面可选上传，带「创建」「取消」
- 空状态设计：素材库/分镜页无数据时显示居中图标 + 文案 + 引导按钮，不用空白表格

# 视觉规范（可验收标准）
- 字体栈：-apple-system, "SF Pro Display", "PingFang SC", "Microsoft YaHei"
- 配色：浅色模式近白背景（#f5f5f7）+ 纯黑文字 + 蓝色主色（#0071e3）；深色模式纯黑背景（#000）+ 白字
- 圆角：卡片 20px，按钮胶囊形；阴影仅用柔和大范围低透明度阴影
- 留白：板块间距 ≥ 96px，卡片内边距 ≥ 24px，标题字号 56–72px 且字距 -0.02em
- 动效：过渡 0.3s ease，卡片悬停 translateY(-4px)，页面进入有轻微上浮渐显，禁止花哨弹跳
- 页面底部可滚动触发淡入动画

# 交付格式
- 单个可运行的 HTML 文件（内联 Tailwind CDN + 少量原生 JS）或 React 单页
- 桌面端 1440px 宽为基准，窄屏自动折叠导航
- 所有按钮有 hover/active 状态，所有文案用中文，示例数据用真实感的漫剧项目名（如《剑来》《诡秘之主》）
```
