# AI 漫剧本地平台 V1 实施规格

> 日期：2026-07-28  
> 依据：`AI漫剧平台-V1核心设计文档`  
> 状态：已按用户提供的设计文档批准实施

## 1. 范围

严格实现设计文档的七步生产链和九个页面。配音、字幕、口型、BGM、最终合成、
账号、多用户和云端发布均不进入 V1。

## 2. 技术方案

- 后端：Python 3.11、FastAPI、Pydantic v2、SQLAlchemy 2.0 Core、Alembic。
- 前端：Vite、React、TypeScript、TanStack Query、Tailwind CSS、shadcn 风格组件。
- 存储：SQLite WAL + 本地文件系统。
- 后台任务：一张持久化 Job 表 + Text/Image/Video 三类本地线程池。
- 测试：pytest、Vitest、Playwright。

## 3. Provider

三类 Provider 均通过 Adapter 注册表解析。

- `mock`：默认 Provider，不需要密钥。Text 产生符合 Schema 的结构化内容；Image 产生
  可解码 PNG；Video 通过持久化模拟服务商任务和 FFmpeg 产生可播放 MP4。
- `openai_compatible`：文字接口使用 OpenAI-compatible chat completions 协议。
- `http_image`：可配置同步或异步 HTTP 图片接口及结果字段路径。
- `http_video`：可配置提交、轮询、下载协议及本地关键帧的 Base64/上传方式。

真实 Provider 的特有限制由 Adapter 校验，通用数据表不固化时长、尺寸或参考图上限。

## 4. 文档歧义的实施决策

1. 提取时遇到同类型同名素材：合并更新现有记录；手工新增重复名称返回 409。
2. `source_signature` 始终指生成时的小说或剧本来源签名；`own_signature` 对当前完整
   可编辑内容计算。
3. 人工修改已确认文本后，状态回到 `ready`，修订号增加；旧媒体仅显示失效，不删除。
4. 上传的媒体版本成功后自动成为当前版本；生成完成的媒体版本也自动成为当前版本。
5. 当前媒体版本不允许直接删除，API 返回 409；用户先切换或取消当前版本。
6. `reference_bindings_json` 使用带 `role` 的判别联合结构，明确区分素材图片与上一镜关键帧。
7. `job.result_json` 保存 Provider 任务恢复和诊断信息，媒体版本表是最终业务事实来源。
8. 只有 `queued` Job 可取消；已经开始或已提交到服务商的任务不可取消。
9. 图片/关键帧下载在 `running` 内完成；视频保留单独的 `downloading` 状态。
10. 视频下载失败不重新提交付费任务，保留 task ID 与结果信息供原任务重试。
11. 开发模式前后端分离；构建后由 FastAPI 同源托管 SPA 与 `/media`。

## 5. 漫剧领域规则

- 项目画风编译为唯一 `STYLE_ANCHOR`，注入所有图片和视频提示词。
- 角色的稳定外貌、发型、服装、标志性特征形成一致性锚点并跨镜头复用。
- 素材只提取当前小说真正涉及的角色、场景和剧情物品，同名内容去重。
- 一个分镜只承载一个主要动作；明确人物站位、视线、方向、起止状态和连续性钩子。
- 视频提示词按时间段描述动作，包含镜头、环境动态、非说话角色反应和禁止事项。
- 内容安全编译器用温和、可视化表达替换高风险词，不改变用户编辑的核心剧情。
- 参考图使用明确版本 ID 绑定，缺失时给出警告并允许纯文字降级。

## 6. 视觉系统

定位为“创作导演台”，不是通用后台模板。

- 画布：温暖浅灰 `#F2F0EA`，主文字 `#191A17`，侧栏墨色 `#1C211F`。
- 强调色：朱砂橙 `#E8613A`，仅用于主动作、当前步骤与告警。
- 字体：Manrope 负责数字与拉丁，中文使用本机清晰黑体栈；标题通过字重与字距塑造识别。
- 容器：少量圆角、细边界、充足留白；避免紫色渐变、装饰性图标和无意义统计。
- 核心路径：项目切换和七步生产链始终可见，任一生产页面三步内可发起核心操作。
- 空状态、失败、缺少 Provider/参考图均提供下一步动作，不出现空白页或纯错误码。

## 7. 完成标准

- Mock Provider 下端到端链路可重复跑通，刷新与服务重启后数据仍在。
- 三类 Provider 可独立配置、测试和选择默认项。
- 十张表、媒体目录、签名、版本唯一性和任务恢复符合设计。
- 九页均具备文档列出的核心操作。
- 后端、前端、构建与 Playwright 主链路通过。
- 浏览器逐页无控制台错误，桌面与窄屏均可使用。
