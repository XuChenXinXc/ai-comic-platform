# V1 验收清单

## 一、启动与持久化

- [ ] `setup.ps1` 在干净环境安装后端、前端与 Chromium。
- [ ] `start-dev.ps1` 启动后可访问前端和 `/docs`。
- [ ] `build.ps1` 后可由 `start.ps1` 单进程访问。
- [ ] SQLite 已启用 WAL、外键与 5 秒 busy timeout。
- [ ] 刷新页面后项目、文字结果、媒体版本和任务仍存在。

## 二、七步生产链

- [ ] 创建项目，保存/上传 TXT 或 Markdown 小说正文。
- [ ] 生成、编辑、保存、确认小说分析。
- [ ] 生成、编辑、增删排序、保存、确认剧本场次。
- [ ] 提取角色、场景、物品并可新增、编辑、合并、删除。
- [ ] 单项或批量生成素材提示词与负向提示词。
- [ ] 单项或批量生成素材图片，上传本地版本，切换当前版本。
- [ ] 从小说和从剧本两种来源提取分镜。
- [ ] 分镜可编辑、增删、拆分/复制/合并和重排。
- [ ] 单项或批量生成分镜图像提示词和视频提示词。
- [ ] 单项、场次或全部生成关键帧并管理版本。
- [ ] 单项、场次或全部生成单镜视频并管理版本。
- [ ] 单个视频可下载，当前版本视频可批量导出 ZIP。

## 三、任务与异常

- [ ] 三类 Provider 可独立配置、设默认和测试连接。
- [ ] API Key 正文不写入数据库。
- [ ] 批量中一个 Mock 失败项不影响其他项完成。
- [ ] 失败项可单独重试，queued 项可取消，已提交项不可取消。
- [ ] 视频 `provider_task_id` 在等待前已持久化。
- [ ] 重启后 `waiting_provider` 视频继续轮询而不重复提交。
- [ ] 下载失败只重试下载。
- [ ] 修改上游后旧媒体显示“来源已变化”，旧文件不被删除。
- [ ] 当前版本唯一；当前版本不能直接删除。
- [ ] 参考图缺失时显示具体警告并允许纯文字生成。

## 四、媒体

- [ ] Mock 图片为有效 PNG，浏览器可预览。
- [ ] Mock 视频为有效 MP4，浏览器可播放，ffprobe 可读取时长。
- [ ] 所有远程结果先进入 `.part`，校验后原子移动到正式目录。
- [ ] 数据库只保存项目目录下的相对媒体路径。
- [ ] 重新生成创建递增版本，绝不覆盖旧文件。

## 五、质量

- [ ] `ruff check` 通过。
- [ ] 后端 pytest 通过。
- [ ] 前端 lint、Vitest、生产构建通过。
- [ ] Playwright 主链路通过。
- [ ] 1440×900、1280×720 和 390×844 视口无布局阻断。
- [ ] 浏览器主链路无 `console.error` 和未处理请求错误。
- [ ] 九个页面均有加载、空、失败和可执行恢复状态。
