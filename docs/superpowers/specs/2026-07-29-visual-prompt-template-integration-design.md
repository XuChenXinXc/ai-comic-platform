# 视觉提示词模板接入设计

## 目标

将用户提供的统一风格块、角色/物品/场景设定图模板、分镜图 V2 模板和视频 V2 模板编译进最终提交给图片与视频 Provider 的提示词。

素材提取完成后必须自动具备可直接生图的完整提示词，不再要求用户单独生成或手动补齐提示词。素材档案、最终提示词与素材图片统一收口到一个“素材库”页面。

## 设计

- 后端使用固定模板渲染最终提示词；素材 Profile、人工编辑的素材描述和 AI 生成的素材描述只填充内容，不得替换版面与一致性约束。
- 角色、物品使用 3:2 设定图版面和 `3840x2560`，场景与关键帧使用 16:9 和
  `3840x2160`；提示词比例与 gpt-image-2 请求尺寸保持一致，不受项目比例覆盖。
- 关键帧使用 V2 首帧模板；已绑定的角色、场景、物品或上一镜关键帧按照真实发送顺序标为 `@ImageN`。
- 视频使用 V2 执行模板；`@Image1` 为当前关键帧，其余绑定参考图紧随其后，并与 APIB 的 `image_urls` 顺序一致。
- 已带时间轴的视频执行提示词原样进入【执行】段，不再嵌套第二层时间段；无时间轴时按实际时长补充分段。
- 关键帧负向提示词写入最终图片提示词，视频负向提示词写入【保持】段，兼容没有独立负向字段的 Provider。
- 缺失的 Profile 细节不输出未替换占位符，而以已有素材描述为准；没有参考图时明确说明纯文字降级。
- 素材名称、分镜模板上下文和实际参考图标签纳入媒体签名，相关内容变化后旧产物会显示来源变化。

## 素材提取与最终提示词

- 扩充角色、场景和物品的提取结构，使一次素材提取同时返回模板所需的可见事实、一致性锚点、构图补充和负向约束。
- 提取结果仍保存结构化素材档案与提示词补充字段；后端通过同一个模板编译器生成只读的最终提示词字段。数据库不重复保存第二份完整模板，避免项目画风或素材档案变化后出现两套结果。
- 素材列表、素材详情和生图版本快照使用同一个最终提示词编译结果。页面展示内容与实际提交给 Provider 的内容保持一致。
- 新提取的同名素材合并档案后重新得到最终提示词；已有素材即使尚未重新提取，也能基于当前档案和默认值立即显示完整模板。
- 人工编辑素材档案和提示词补充字段的能力继续保留，保存后最终提示词自动更新；不再提供单个或批量“生成提示词”按钮。
- 原有提示词生成 API 与任务处理器保留，避免破坏已有调用方，但不再作为前端生产流程入口。

## 素材库页面

- 侧边生产轨道只保留一个“素材库”入口，路由为 `/assets`。
- 原“素材与提示词”和“素材图片”的能力合并到同一页面；角色、场景、物品分类 Tab 保留。
- 每个素材项同时展示素材档案摘要、最终提示词、当前图片与历史版本，并保留编辑、确认、删除、上传图片、单个生图和版本管理。
- 页面级操作保留提取当前分类、提取全部、手工新增、重复素材合并、全选和批量生图。
- `/asset-images` 保留为兼容跳转并重定向到 `/assets`，不让旧书签和历史入口落到空白页。
- 只移除提示词生成按钮及其页面调用代码，不删除素材、图片或版本管理能力。

## 分镜提取与最终提示词

- 一次分镜提取同时返回关键帧画面补充、视频时间轴和负向约束，不再把提取结果中的提示词清空，也不再要求用户启动第二个提示词任务。
- 分镜列表额外返回只读的 `compiled_image_prompt` 与 `compiled_video_prompt`；两者由固定 V2 模板、项目画风、分镜结构和当前参考绑定实时编译，页面展示的内容与实际生产模板保持一致。
- 分镜页面移除单个和批量“生成/补齐提示词”按钮；保留分镜提取、结构编辑、可选导演补充、单个/批量关键帧生成、单个/批量视频生成及版本管理。
- 原有分镜图片提示词、视频提示词和批量提示词 API 继续保留，兼容已有调用方，但不再作为前端生产流程入口。

## 验证

- 后端测试断言素材提取后无需第二个提示词任务即可返回完整最终提示词，并覆盖角色、物品、场景模板字段。
- 后端测试断言素材列表展示的最终提示词与生图版本的 `prompt_snapshot` 完全一致。
- 单元测试断言三类素材最终提示词含对应版面、统一风格块和负向约束。
- 单元测试断言关键帧/视频提示词含 V2 分段及 `@ImageN` 映射。
- Provider 测试断言 APIB 的 `image_urls` 同时携带当前关键帧和绑定参考图。
- 前端测试断言导航只有“素材库”，素材库内同时存在档案、提示词和图片操作，且不再出现生成提示词按钮。
- 路由测试断言 `/asset-images` 自动重定向到 `/assets`。
- 后端流程测试断言分镜提取后不调用提示词任务即可直接生成关键帧和视频，并能读取完整 V2 模板。
- 前端测试断言分镜页显示完整 V2 关键帧/视频提示词，且不再出现单个或批量提示词生成按钮。
