# 剧本驱动分镜流水线与生产规格设计

日期：2026-07-29

## 目标

将创作流程固定为：

`小说原文 → 后台小说分析 → 生成剧本 → 从剧本提取分镜 → 生成关键帧 → 生成视频`

同时解决图片预览、场景素材绑定、视频时长类型和固定生产规格问题。

## 已确认设计

### 图片预览

- 素材图片、分镜关键帧及其历史图片版本均支持点击放大。
- 使用统一弹窗按原比例完整展示。
- 历史版本的设为当前、下载和删除能力保持不变。

### 场景素材绑定

- 分镜提取只读取当前剧本。
- 提取时向文字模型提供当前项目的角色、场景和物品素材目录。
- 模型优先返回目录中的素材 ID，后端校验素材归属和类型。
- 兼容仍返回名称的模型：依次执行完全名称、标准化名称和唯一别名匹配。
- 无法唯一匹配时不猜测绑定，并返回明确警告。
- 没有场景素材时阻止分镜提取，提示先提取素材。

### 视频时长与规格

- 新提取分镜的时长由镜头内容决定，并使用整数秒。
- Grok 视频 Provider 请求中的 `duration` 始终序列化为整数。
- 历史小数时长在单次视频生成上下文中向上取整，不修改原分镜记录。
- 视频提示词、视频版本记录、签名和 Provider 请求使用相同的有效时长。
- `grok-imagine-1.5-video-apimart` 与 `grok-imagine-1.5-video-ext`
  默认使用 `16:9` 和 `1080p`。

### 写作页

- 页面仅展示剧本生成及现有剧本编辑能力。
- 小说分析页面入口和编辑界面隐藏。
- 生成剧本任务内部先执行并保存现有小说分析逻辑，再使用本次分析结果生成剧本。
- 小说分析的数据表、接口、提示词、校验和并发保护保留。

### 项目页与图片尺寸

- 删除生产基准展示和选择。
- 项目页保留小说、统一画风和默认 Provider 配置。
- 不再从项目默认时长初始化分镜。
- 固定图片尺寸：
  - 角色基图：`3840x2560`
  - 场景图：`3840x2160`
  - 物品图：`3840x2560`
  - 分镜关键帧：`3840x2160`
- 视频默认为 `16:9`、`1080p`。
- 旧项目字段保留数据库兼容，但不再驱动新流程。

## 验收标准

- 点击素材图或关键帧可打开大图并关闭。
- 页面不再出现小说分析 Tab、分镜来源选择和生产基准区域。
- 生成剧本时先产生最新小说分析，再产生剧本。
- 新分镜提取请求固定使用剧本，且可绑定项目中的场景素材。
- Grok 请求体中的 `duration` 是 JSON 整数，默认 `quality` 为 `1080p`。
- 四类 GPT Image 2 图片请求使用固定尺寸。
- 后端目标测试、前端目标测试、ruff、前端构建通过。
