# 自由制作默认场景选择设计

## 目标

自由制作进入项目并初始化空分镜时：没有场景素材则保持不选中；有一个或多个场景素材时，默认选中素材列表中的第一个场景。

用户手动选择“不使用场景素材”并保存后，后续素材刷新或切换项目回来时保持空值，不被默认逻辑覆盖。

## 范围与实现

- 只修改前端 `CustomShotsPage` 的自由制作初始化逻辑，不改变常规分镜和后端接口。
- 从当前项目素材列表中按现有返回顺序找到第一个 `asset_type === "scene"` 的素材，作为默认场景 ID。
- 初始化分镜草稿时，仅对尚未完成默认初始化且没有 `scene_asset_id` 的分镜应用默认场景。
- 使用现有 `localStorage` 记录已完成默认初始化的分镜 ID。这样后端保存的空 `scene_asset_id` 可以明确表示用户主动取消选择，而不是待初始化状态。
- 已有非空场景选择、无场景项目和用户主动取消选择均保持原值。

## 测试

增加纯函数测试，覆盖：

1. 没有场景素材时返回空默认值；
2. 一个场景素材时返回该素材 ID；
3. 多个场景素材时返回列表中的第一个场景 ID；
4. 初始化逻辑不覆盖已有场景选择或已记录的用户取消选择。
